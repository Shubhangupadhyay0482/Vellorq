# VELLORQ — Automotive Care Website

A responsive, multi-section single-page website built with plain HTML, CSS and JavaScript. No framework or build step required.

## Run locally

1. Extract the `vellorq-website.zip` file.
2. Open `index.html` in your browser, or use VS Code Live Server.

## Before publishing

1. Open `script.js` and replace `91XXXXXXXXXX` with the Vellorq WhatsApp number (country code + number, digits only).
2. Replace the current photography with original Vellorq work as it becomes available. The current Unsplash image URLs are remote and require an internet connection; check each image licence/terms and replace with your own licensed brand photography before commercial launch.
3. Update the service list, location, business hours and contact details to match the real business.
4. Add a real domain and social links when available.

## Files

- `index.html` — page structure and content
- `style.css` — responsive visual design
- `script.js` — mobile navigation and WhatsApp enquiry form
- `assets/favicon.svg` — Vellorq monogram favicon

The service descriptions are intentionally written without unsupported performance claims, fabricated reviews or invented business statistics.
